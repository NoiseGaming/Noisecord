# Noisecord

A fan-made Pizza Tower / The Noise themed native Windows Discord client, based on [Yapfast](https://github.com/yapfast/yapfast).

## Download

Open [Releases](https://github.com/NoiseGaming/Noisecord/releases), download **Noisecord-Windows-x64.zip**, extract it, and run **Noisecord.exe**. Sign in with your own account. No installer required.

Windows x64 preview; unsigned. Includes custom icons, backgrounds, font, and sounds. The latest build uses the Noise-face Copy icon and uppercut sounds for stream viewers joining and leaving.
